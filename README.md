Sorting Algorithms Activity

1. Program Description

This is a Java program which demonstrates the use of three different sorting algorithms: Bubble Sort, Selection Sort and Insertion Sort.

I used an array of 10 numbers. Each sorting method has its own copy of the original array. The program displays 
the numbers and the results of each method after they have been sorted. All the numbers are in ascending order.

2. Explanation of the Three Sorting Algorithms

A. Bubble Sort

Bubble sort looks at two numbers at a time. If the first number is bigger than the 
second one they swap. It continues doing that until all the numbers are in order.

B. Selection Sort

Selection sort looks for the number and puts it in the first position. It then looks for the 
next smallest number and puts that in the next position. It does this again and again until all the numbers are sorted.

C. Insertion Sort

Insertion sort works by fixing the numbers one at a time. It takes
a number, works out where it should go and if the numbers before it are bigger they shift to the right to make space.

3. Differences Between the Three Sorting Algorithms

The three algorithms all have the same objective, they just
go about sorting the numbers in different ways.

Bubble sort: looks at two numbers at a time and swaps them if they're in the wrong order.

Selection sort: looks for the number and puts it in the right place.

Insertion sort: takes one number at a time and puts it in the right place.

4. Reflection Questions

1. How does each sorting algorithm go about arranging the numbers? What's the difference in their processes?

Bubble Sort looks at adjacent values and swaps them if they're out of order. Selection Sort looks
for the value that should be in a particular position and puts it there. Insertion Sort takes one value at a time and inserts it in the correct position.

They're different in that they each have their own way of sorting the numbers, but they all end up with the same answer.

2. Of the three sorting algorithms, which one do you think is the easiest to understand and implement? Why?

Bubble Sort is the one that I find easiest as the steps are very simple. You just look at two numbers and swap 
them if they are in the wrong order. It's very easy to follow and to understand.

3. If the numbers are already sorted, which algorithm do you think would be the better one? Give your reason for that based on how the algorithms actually work.

I think Insertion Sort would do better if the numbers were already sorted. They'd already be in the right place 
so there'd be no need to move them. It would just need to look at the numbers and that would be it. Much faster.

4. What would happen if you added numbers to your array? How would that impact the performance of each of the sorting algorithms?

If I'm adding numbers the program will take longer to sort them. The algorithms
will have numbers to look at and sort. That means the sort could well take longer, particularly if the array is full of numbers.

5. As a programmer why do you need to know about all the different sorting algorithms rather than just use one?

It's important to learn about sorting algorithms as they all work in different ways. Some are better in certain situations
than others. As a programmer it's going to help me choose the right one and it'll also improve my programming.
