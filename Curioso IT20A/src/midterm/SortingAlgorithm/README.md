Sorting Algorithms in Java

About the Program
Kini nga program nagpakita kung giunsa pag-sort ang mga numbers gamit ang tulo ka algorithms: Bubble Sort, Selection Sort, ug Insertion Sort.

Ang ilang tumong kay i-arrange ang numbers gikan sa pinakagamay hangtod sa pinakadako.

Three Sorting Algorithms

1. Bubble Sort

Mag-compare sa duha ka numbers nga magtapad. Kung sayop ang ilang order, mag-ilis sila og position.

2. Selection Sort

Mangita sa pinakagamay nga number ug ibutang kini sa sakto nga position.

3. Insertion Sort

Magkuha og usa ka number matag higayon ug ibutang kini sa sakto nga lugar.

Original Array
```text
[64, 25, 12, 22, 11, 90, 34, 5, 78, 43]
```

Program Output
```text

Original Array:
[64, 25, 12, 22, 11, 90, 34, 5, 78, 43]

Bubble Sort Result:
[5, 11, 12, 22, 25, 34, 43, 64, 78, 90]

Selection Sort Result:
[5, 11, 12, 22, 25, 34, 43, 64, 78, 90]

Insertion Sort Result:
[5, 11, 12, 22, 25, 34, 43, 64, 78, 90]
```

How to Run the Program
1. Ablihi ang imong Java IDE.
2. Create og Java project.
3. Create og class nga ang name kay `SortingAlgorithm`.
4. I-copy ug paste ang code.
5. I-run ang program para makita ang output.
