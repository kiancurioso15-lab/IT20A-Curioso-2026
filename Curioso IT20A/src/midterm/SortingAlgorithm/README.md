Sorting Algorithms Activity

1. Program Description

Kini nga Java program nagpakita sa paggamit sa tulo ka sorting algorithms: Bubble Sort, Selection Sort, ug Insertion Sort.

Naggamit kini og array nga adunay 10 ka numero nga wala pa mahan-ay. Ang matag sorting algorithm adunay kaugalingong kopya sa original array aron dili mausab ang orihinal nga mga numero. Gipakita sa programa ang original array ug ang resulta sa matag sorting method human mahan-ay ang mga numero gikan sa pinakagamay hangtod sa pinakadako.

2. Explanation of the Three Sorting Algorithms

A. Bubble Sort

Ang Bubble Sort magkumpara sa duha ka numero nga magtapad. Kung mas dako ang unang numero kaysa ikaduha, mag-ilis sila og pwesto. Balikon kini nga proseso hangtod mahan-ay ang tanang numero.

B. Selection Sort

Ang Selection Sort mangita sa pinakagamay nga numero sa wala pa mahan-ay nga parte sa array. Kung makit-an na kini, ibutang kini sa hustong pwesto. Balikon kini nga proseso hangtod mahuman ang paghan-ay sa tanang numero.

C. Insertion Sort

Ang Insertion Sort maghan-ay sa mga numero tagsa-tagsa. Mokuha kini og usa ka numero ug ikumpara sa mga numero nga naa sa wala aron makit-an ang hustong pwesto niini. Kung mas dako ang mga numero sa wala, ibalhin kini sa tuo aron makahimo og lugar.

3. Differences Between the Three Sorting Algorithms

Ang tulo ka algorithms pareho og tumong, nga mao ang paghan-ay sa mga numero gikan sa pinakagamay hangtod sa pinakadako, pero lahi-lahi ang ilang pamaagi.

- **Bubble Sort:** Magkumpara sa duha ka magtapad nga numero ug mag-ilis sa ilang pwesto kung sayop ang pagkahan-ay.
- **Selection Sort:** Mangita sa pinakagamay nga numero ug ibutang kini sa hustong pwesto.
- **Insertion Sort:** Mokuha og usa ka numero matag higayon ug ibutang kini sa sakto nga pwesto taliwala sa mga numero nga nahan-ay na.
